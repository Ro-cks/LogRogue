# LogRogue

장비 프로그램이 날짜별로 쌓는 로그 폴더를 기간 단위로 압축하고, 원하면 원본을 삭제해 디스크 공간을 확보하는 Windows 데스크톱 유틸리티입니다.

> 현재 버전: **0.1.0 (개발 중)**

## 주요 기능

- **기간 지정 압축** — 시작일~종료일에 해당하는 날짜 폴더를 날짜별 ZIP 파일로 압축
- **압축 전 확인 창** — 대상 날짜, 파일 수, 용량, 저장 위치, 삭제 방식을 미리 보여주고 확인 후 실행
- **압축 무결성 검증** — 압축 파일을 다시 열어 파일 개수·이름·해제 크기를 원본과 하나하나 대조
- **원본 삭제 (선택)** — 휴지통 이동 또는 영구 삭제 중 선택, 검증에 성공한 날짜만 삭제
- **결과 목록** — 날짜별 원본·압축 용량, 감소율, 삭제 여부, 저장된 파일명을 표로 표시
- **백그라운드 처리** — 압축·삭제 중에도 창이 멈추지 않고 진행 상황 표시

텍스트 로그 기준으로 **약 90% 이상** 용량이 줄어듭니다. (샘플 76.5 MB → 5.8 MB)

## 대상 로그 폴더 구조

대상 폴더 바로 아래에 `yyyy-MM-dd` 형식의 날짜 폴더가 있는 구조를 전제로 합니다.

```
대상 폴더\
├── 2026-08-17\
│   ├── globalfile\2026-08-17_global.log
│   ├── errorfile\2026-08-17_error.log
│   ├── eventfile\ER_0807_PRsInspResultErr.log
│   └── ...
├── 2026-08-18\
└── ...
```

- 기간 판정은 파일명이 아니라 **날짜 폴더명** 기준입니다. 파일명에 날짜가 없는 로그도 누락되지 않습니다.
- 날짜 형식이 아닌 폴더는 무시합니다.
- 날짜 폴더 하나가 ZIP 파일 하나가 됩니다. (`2026-08-20` → `2026-08-20.zip`)
- 압축을 풀면 날짜 폴더 구조가 그대로 복원됩니다.

## 안전 설계

원본 로그를 삭제할 수 있는 프로그램이므로 아래 원칙을 지킵니다.

**오늘 날짜 폴더는 절대 건드리지 않습니다.**
장비가 기록 중인 파일이 있을 수 있으므로, 기간에 오늘이 포함되어도 오늘 및 미래 날짜 폴더는 대상에서 제외합니다.

**깨진 압축 파일을 남기지 않습니다.**
임시 파일(`.zip.tmp`)에 압축하고 검증을 통과한 뒤에만 최종 이름으로 바꿉니다. 도중에 실패하거나 프로그램이 종료되어도 출력 폴더에는 완전한 ZIP만 남습니다.

**기존 압축본을 함부로 덮어쓰지 않습니다.**
같은 날짜의 ZIP이 이미 있을 때, 새 압축본이 기존 파일을 모두 포함하면 교체하고, 하나라도 빠져 있으면 기존 것은 그대로 두고 `2026-08-20_2.zip`처럼 번호를 붙여 따로 저장합니다. 이전 실행에서 삭제가 도중에 멈춘 경우에도 이미 지워진 파일의 유일한 압축본이 사라지지 않습니다.

**삭제 직전에 다시 확인합니다.**
원본 삭제는 해당 날짜의 압축과 검증이 성공한 직후에만 수행하며, 실제로 지우기 전에 아래를 모두 재확인합니다.

1. 압축 파일이 검증 당시 크기 그대로 존재하는가
2. 지우려는 폴더가 대상 폴더 바로 아래의 날짜 폴더인가
3. 오늘 이전 날짜인가
4. 폴더 안의 파일을 다른 프로그램이 사용하고 있지 않은가

하나라도 어긋나면 그 날짜는 삭제하지 않고 사유를 결과 목록에 표시합니다.

**출력 폴더는 대상 폴더 밖에 있어야 합니다.**
출력 폴더가 대상 폴더와 같거나 그 안에 있으면 실행을 거부합니다.

## 삭제 방식

| 방식 | 특징 |
|---|---|
| 휴지통으로 이동 | 실수 시 되살리기 쉬움. **휴지통을 비우기 전까지 디스크 공간은 확보되지 않음** |
| 영구 삭제 | 즉시 공간 확보. 되돌리려면 ZIP에서 복원 |

- 네트워크 드라이브처럼 휴지통이 없는 위치이거나 휴지통 용량보다 큰 경우, Windows가 휴지통 이동을 영구 삭제로 처리합니다.
- 영구 삭제를 선택하면 확인 창에서 Enter 키로 실행되지 않으며, 버튼을 직접 눌러야 합니다.

## 실행 환경

- Windows 10 / 11 (x64)
- .NET 10

## 빌드

### 요구 사항

- Visual Studio 2022 (최신 업데이트) 또는 Visual Studio 2026
- **.NET 데스크톱 개발** 워크로드
- .NET 10 SDK

### 빌드 및 실행

1. `LogRogue.sln`을 Visual Studio로 엽니다.
2. 솔루션 탐색기에서 `LogRogue.App`이 시작 프로젝트(굵은 글씨)인지 확인합니다.
3. `F5`로 실행합니다.

### 배포용 단일 실행 파일

`LogRogue.App` 우클릭 → **게시** → 폴더 대상, `win-x64`, 자체 포함, 단일 파일 생성 옵션으로 게시하면 .NET 런타임 설치 없이 실행되는 `LogRogue.exe` 하나가 만들어집니다.

## 사용 방법

1. **대상 폴더**에 날짜 폴더들이 들어 있는 로그 루트 폴더를 지정합니다.
2. **출력 폴더**에 압축 파일을 저장할 위치를 지정합니다. (대상 폴더 밖)
3. **시작일 / 종료일**을 고릅니다. 기본값은 30일 전부터 어제까지입니다.
4. 원본을 지우려면 **원본 삭제**를 체크하고 삭제 방식을 고릅니다.
5. **실행**을 누르면 확인 창이 뜹니다. 대상과 삭제 방식을 확인하고 시작합니다.
6. 결과 목록에서 날짜별 처리 결과를 확인합니다.

> 처음 사용할 때는 실제 로그 폴더를 복사한 사본으로 먼저 테스트하는 것을 권장합니다.

## 프로젝트 구조

```
LogRogue.sln
├── LogRogue.Core            UI와 무관한 핵심 로직
│   ├── Scanning\
│   │   ├── FolderScanner.cs       날짜 폴더 탐색, 기간 판정
│   │   ├── LogDayFolder.cs        날짜 폴더 정보 (날짜, 경로, 파일 수, 용량)
│   │   └── ByteSize.cs            용량 표시 형식
│   ├── Archiving\
│   │   ├── DayFolderArchiver.cs   압축, 검증, 저장 위치 결정
│   │   └── ArchiveResult.cs
│   ├── Deletion\
│   │   ├── SourceDeleter.cs       삭제 전 안전 확인, 휴지통 이동, 영구 삭제
│   │   ├── DeleteMode.cs
│   │   └── DeletionResult.cs
│   ├── BackupJob.cs               전체 흐름 (Prepare → Run)
│   ├── BackupPlan.cs
│   ├── BackupProgress.cs
│   └── DayBackupResult.cs
│
├── LogRogue.App             WinForms 화면
│   ├── Form1.cs                   메인 창
│   └── PreviewForm.cs             압축 전 확인 창
│
└── LogRogue.Core.Tests      단위 테스트 (xUnit)
```

핵심 로직은 `LogRogue.Core`에 모여 있고 화면(`LogRogue.App`)은 이를 호출만 합니다. 이후 스케줄 실행이나 명령줄 실행을 붙일 때 같은 로직을 그대로 재사용하기 위한 구조입니다.
